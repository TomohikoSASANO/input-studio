FAQ

このサービスで何ができますか？

PDFを読み込み、入力項目を配置・編集し、完成PDFをダウンロードできます。プロジェクトZIPとして保存・再開も可能です。

保存したプロジェクトはどの形式ですか？

プロジェクトはZIP形式で保存され、再開時に同じ編集状態を読み込めます。

対応ブラウザを教えてください。

最新版の Chrome / Edge / Firefox / Safari を推奨します。

広告が表示されないことがあります。

広告ブロッカー、配信在庫、AdSense審査状態などにより、広告が表示されない場合があります。

問い合わせ先はどこですか？

お問い合わせページをご利用ください。
