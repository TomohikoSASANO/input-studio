PDF結合/分割ガイド

PDF Input Studioでは、PDF追加による結合運用と、ページ削除・並べ替えによる分割運用に対応しています。

PDF結合（PDF merge）

  1. 既存のプロジェクトZIPを開く
  2. 「PDF追加」から追加PDFを選択
  3. ページ順を確認して保存

PDF分割運用（PDF split workflow）

  1. 対象ページを「現在ページ削除」で整理
  2. 必要に応じて「PDF並べ替え」で順序調整
  3. 用途ごとにプロジェクト保存またはPDFダウンロード
