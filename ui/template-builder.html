How It Works

From blank PDF to automated output in minutes

01
Upload your PDF template

Open any existing PDF - a contract, invoice, report, or form - in the browser-based editor.

Drag & drop or file picker
02
Place {{tags}} in text fields

Click any text area and insert a tag placeholder. Name it anything - {{client}}, {{date}}, {{ref_no}}.

Auto-detected across pages
03
Fill the tag panel once

Enter values in the sidebar. All matching tags in all connected documents update in real time - no find-and-replace needed.

Instant sync across documents
04
Export as PDF or ZIP bundle

Download individual PDFs or export the whole project as a ZIP - template included. Perfect for archiving or handing off.

One-click export
05
Save and reuse the template

Save the template configuration for the next project. Reload it, change a few values, and you are done.
